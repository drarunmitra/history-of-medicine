# Image credits for L3 (The birth of public health)

All 16 files were downloaded from Wikimedia Commons (image files only, jpg, not opened with any program other than an image viewer). Licence and author are as stated on each Commons file page on 6 Nov 2026. Public-domain items need no credit by law but the slide source line should still name the source. CC BY needs author/holder and licence on the slide. CC BY-SA also needs the licence named, and any derivative must carry the same licence.

Not found with a clear licence, so not included: Farr's cholera-elevation chart, Bhore Committee imagery, a photograph of Saiban Bibi (India's last case). The CDC image of Rahima Banu (Bangladesh, 1975) is included as the closest image for the eradication story, and it is not India's last case.

## Checks and caveats
- Licence data comes from Commons metadata. For Public domain items that are scans of old works the copyright status in India follows the rule of the author's death date; all creators above died more than 60 years ago except the CDC photograph (US government work) and the Wellcome scans (CC BY).
- `alma_ata_conference_1978.jpg`: the Commons page did not return an author name through the API; open the page and confirm before projecting.
- `chadwick_portrait.jpg`: Commons lists the source as a heritage-site timeline image; the photograph is 19th century, but the photographer is not named.
- `shattuck_portrait.jpg`: Commons attributes the page to a book digitised by the Internet Archive; the portrait's maker is not named.
- Each file was viewed once to confirm that the content matches the description above (Chadwick title page, Farr table, Snow/Soho map, Doré engraving, Farr and Chadwick portraits).
